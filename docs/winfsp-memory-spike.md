# WinFsp 메모리 마운트 기술 검증

이 스파이크는 SFTP를 연결하기 전에 WinFsp 자체의 설치, 드라이브 문자 생성,
Windows 탐색기 기본 파일 작업을 분리해 확인한다. 저장된 데이터는 메모리에만
있으며 프로그램 종료 시 사라진다.

## 준비

1. Windows 10/11 64-bit에 WinFsp를 설치한다.
2. Go 1.26 이상을 설치한다.
3. 사용 중이지 않은 드라이브 문자를 확인한다.

## 빌드와 실행

```powershell
go build -o bin/dkdrive-memfs.exe ./cmd/dkdrive-memfs
.\bin\dkdrive-memfs.exe -mount X:
```

관리자 권한은 기본 요구사항이 아니다. 마운트에 실패하면 WinFsp 설치 여부와
`X:`가 이미 사용 중인지 먼저 확인한다.

## 수동 점검

탐색기에서 `X:`를 열고 다음 순서로 확인한다.

- `한글 폴더` 생성
- `hello world.txt` 생성 후 메모장으로 저장
- 파일을 `한글 폴더`로 이동
- 파일 이름 변경
- 파일 덮어쓰기
- 파일과 폴더 삭제
- 긴 파일명과 공백 포함 파일명 생성

각 작업이 끝난 뒤 탐색기 새로고침을 수행한다. 프로그램 콘솔에서 `Ctrl+C`를
누르면 마운트를 해제한다.

## 완료 기준

- 마운트와 해제가 오류 없이 끝난다.
- 탐색기에서 생성, 읽기, 쓰기, 이동, 이름 변경, 삭제가 동작한다.
- 메모장에서 새 파일 저장과 기존 파일 덮어쓰기가 동작한다.
- 한글과 공백 포함 파일명이 손상되지 않는다.

이 검증이 끝나면 같은 마운트 경계에 DKDrive의 SFTP 백엔드를 연결한다.

## 검증 결과

- 날짜: 2026-08-26
- 환경: Windows 64-bit, WinFsp 2.1.25156
- 마운트: `X:` 드라이브 생성 성공
- 통과: 한글·공백 포함 폴더 및 파일 생성
- 통과: 파일 읽기와 추가 쓰기
- 통과: 폴더 간 이동과 한글 이름 변경
- 통과: 파일 및 폴더 삭제

WinFsp 런타임과 `go-winfsp` 네이티브 계층을 이용한 기본 파일 작업이 실제
Windows 환경에서 동작함을 확인했다. 다음 검증은 SFTP 백엔드를 연결한 뒤
동일 작업을 원격 서버 대상으로 반복한다.
