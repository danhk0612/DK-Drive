# DK-Drive 0.9.1

후속 0.9.2에서 WinFsp를 함께 설치하는 Windows 설치형 EXE를 추가했습니다. 신규 다운로드는 0.9.2를 권장합니다.

제작자: 참빛바다 · Windows 10/11 64비트

- WinFsp 2.1.25156 공식 MSI를 수정 없이 ZIP에 동봉했습니다. 별도 다운로드가 필요 없습니다.
- ZIP 전체를 풀고 dkdrive.exe를 실행하면 WinFsp 미설치 시 설치를 안내합니다.
  관리자 승인을 거쳐 설치한 뒤 DK-Drive를 다시 실행하세요. 설치 프로그램이 요구하면 Windows를 재시작하세요.
- 이미 WinFsp가 정상 설치되어 있으면 재설치하지 않습니다.
- 실행 전과 패키징 시 MSI의 SHA-256을 공식 배포 값과 대조합니다.
- 프로그램의 정보 / 라이선스 화면과 사용자 문서에 WinFsp 고지·링크를 추가했습니다.
- DK-Drive는 MIT를 유지하며 WinFsp의 GPLv3 + FLOSS 예외를 적용합니다.
  WinFsp 및 Go 런타임·의존 라이브러리의 원본 라이선스를 licenses에 포함했습니다.
- 0.9.0의 탐색 성능 개선과 복구 기능을 유지합니다. 기존 공개 파일은 교체하지 않습니다.

설정·비밀번호·보존 캐시는 업데이트로 삭제되지 않습니다. 기존 프로그램을 트레이에서 종료하고 새 ZIP을 풀어 실행하세요.
Windows CI에서 패키징·체크섬·라이선스 동봉·공식 MSI 설치 및 DLL 로딩을 확인합니다.
사용자 PC의 UAC/설치 화면 조작과 실제 NAS 동작은 자동 검증과 별개입니다.
로그인·시스템 종료·장시간 및 전송 중 단절·Implicit FTPS 실서버 등 기존 미확인 항목은 유지합니다.
