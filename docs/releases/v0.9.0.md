# DK-Drive 0.9.0

후속 0.9.2에서 WinFsp 설치 파일 동봉과 UI·배포 라이선스 고지, Windows 설치형 EXE를 보완했습니다. 신규 다운로드는 0.9.2를 권장합니다.

제작자: **참빛바다** · Windows 10/11 64비트 · WinFsp 2.1 이상 별도 설치 필요

## 주요 변경

- SFTP·WebDAV·FTP/FTPS 원격 저장소를 Windows 드라이브로 연결하는 GUI와 트레이 제공.
- 연결별 메타데이터 캐시, 폴더 목록의 자식 정보 재사용, 동일 동시 조회 병합으로 탐색 성능 개선.
- 수신된 실환경 집계에서 WebDAV 원격 Stat 계열 5,643→42회, Explicit FTPS 5,614→31회 감소.
  사용자 체감 개선 확인. 실행 조건이 완전히 동일하지 않아 정확한 속도 배수나 캐시 적중률은 의미하지 않음.
- 쓰기·삭제·이동·속성 변경과 부분 실패 시 관련 캐시 무효화. 복구 충돌 검사는 원격을 직접 조회.
- 실패한 쓰기 파일의 보존·로컬 내보내기·명시적 원격 재시도 및 충돌 처리.
- EXE 아이콘·제품 정보·버전 0.9.0 / 파일 버전 0.9.0.0, 제작자 참빛바다 적용.
- Windows ZIP과 SHA-256 제공.

## 다운로드와 업데이트

`DK-Drive-0.9.0-windows-amd64.zip`을 내려받아 압축을 풀고 `dkdrive.exe`를 실행한다.
Go 설치는 필요하지 않으며 WinFsp는 별도로 설치해야 한다.
기존 버전은 열린 파일을 저장하고 트레이에서 정상 종료한 뒤 교체한다.
설정·비밀번호·복구 캐시는 ZIP에 포함되지 않으며 프로그램 교체로 삭제되지 않는다.
로그인 자동 실행을 사용하면서 프로그램 위치를 옮겼다면 새 위치에서 자동 실행을 다시 등록한다.
ZIP 안 README.md에 설치·업데이트·복구·제거 절차가 있다.
`.zip.sha256`은 ZIP 체크섬, ZIP 안 `SHA256SUMS.txt`는 EXE 체크섬이다.

## 검증과 알려진 제한

Windows CI 전체 테스트·정적 검사·GUI 빌드·제품 정보·아이콘 로딩·압축/체크섬 검증 통과 후 게시한다.
WebDAV·Explicit FTPS 탐색 체감 개선과 읽기 전용 쓰기 차단/해제 후 쓰기를 실환경에서 확인했다.
기존에 통과한 기본 기능 검증을 유지하며 다음 항목을 모두 새로 검증했다고 주장하지 않는다.

- SFTP의 이번 캐시 적용 전후 성능 비교와 폴더 규모별 정량 표시 시간은 미확인.
- 실제 Windows 로그인·시스템 종료/재시작, 장시간·전송 중 단절 및 실제 업로드 실패 후 강제 해제 조합의 잔여 검증이 남아 있음.
- 새 배포 ZIP을 별도 폴더에 풀어 사용자가 GUI 실행하는 최종 실환경 확인은 미완료.
- Implicit FTPS는 모의 서버 검증 상태이며 실서버 미검증.
- 전송 중단 지점 이어받기, 파일 내용 읽기 캐시, 코드 서명·설치 관리자·자동 업데이트는 미지원.
- 외부에서 변경한 메타데이터는 최대 2초 캐시 후 새로고침 시 반영될 수 있음.
- 저장 비밀값은 Windows 사용자/PC에 종속. 앱·Windows 버퍼의 미전달 데이터는 보존되지 않을 수 있음.

0.9.0은 정식 1.0 전 단계이며, 위 제한을 명시한 사용자 승인 배포다.
