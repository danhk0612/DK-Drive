# DK-Drive 0.9.2

Windows 설치형 배포를 추가했습니다.

- 단일 설치형 EXE가 DK-Drive를 Program Files에 설치하고 시작 메뉴·제거 항목을 등록합니다.
- 공식 WinFsp 2.1 MSI를 설치 파일 안에 포함하며, WinFsp가 없을 때 SHA-256 검증 후 함께 설치합니다.
- DK-Drive를 제거해도 다른 프로그램이 사용할 수 있는 WinFsp는 유지합니다.
- 기존 휴대용 ZIP도 계속 제공하며 앱 설정과 복구 캐시는 업데이트·제거 시 보존합니다.
- CI가 설치형 EXE의 설치, WinFsp 런타임 로딩, DK-Drive 제거와 WinFsp 유지까지 검증합니다.

설치형 EXE와 휴대용 ZIP은 아직 코드 서명되지 않았습니다. 각 파일과 함께 제공되는 `.sha256`으로 다운로드 무결성을 확인할 수 있습니다.
