# DK-Drive Windows 배포판 사용 안내

현재 버전은 0.9.2, 제작자는 참빛바다다. EXE 파일 버전은 0.9.2.0이다.
정식 1.0 전 검증 단계이며 잔여 실환경 검증이 남아 있다.

## 설치와 실행

Windows 10/11 64비트가 필요하다. 일반 사용자는 설치형 EXE를 실행한다. 설치 프로그램은
DK-Drive를 Program Files에 설치하고 시작 메뉴와 제거 항목을 등록한다. WinFsp가 없으면
내장된 공식 MSI의 SHA-256을 확인한 뒤 함께 설치한다. 관리자 승인이 필요하며 설치 프로그램이
재시작을 요구하면 Windows 재시작 후 실행한다. 이미 정상 설치되어 있으면 WinFsp 설치를
건너뛴다. 프로필 저장 후 선택 연결한다.

휴대용 사용은 ZIP 전체를 고정 폴더에 풀고 dkdrive.exe를 실행한다. WinFsp를 사용할 수
없으면 동봉한 공식 설치 파일 실행을 안내한다. 설치 후 DK-Drive를 다시 실행한다.
로그인 시 실행을 사용한다면 실행 파일을 이후 이동하지 않는다.
배포 파일에는 설정·비밀번호·복구 캐시가 포함되지 않는다.

## 업데이트와 되돌리기

열린 원격 파일을 저장하고 연결을 일반 해제한 뒤 트레이에서 종료한다.
설치형은 새 설치 프로그램을 실행하면 기존 설정과 복구 캐시를 유지한 채 업데이트한다.
휴대용은 기존 프로그램 폴더를 보관하고 새 ZIP을 별도 폴더에 풀어 실행한다.
휴대용에서 로그인 시 실행을 사용했다면 새 위치에서 해당 설정을 해제했다가 다시 등록한다.
이전 버전으로 되돌릴 때도 먼저 종료한 뒤 이전 설치 프로그램이나 실행 파일을 사용한다.
설정 형식이 바뀐 미래 버전과의 하위 호환성은 보장하지 않는다.

## 설정과 실패 파일 복구

설정은 %APPDATA%\DKDrive\settings.json, 복구 staging은
%LOCALAPPDATA%\DKDrive\Cache에 저장한다. 앱의 캐시 관리에서 상태를 확인한다.
실패한 파일은 먼저 로컬 내보내기로 보관하고, 연결 복원 후 원격 재시도를 선택한다.
충돌 안내가 나오면 원격 파일과 보존본을 확인한 뒤 처리한다.
캐시 전체 정리는 복구를 마쳤을 때만 사용한다.
저장된 비밀값은 Windows 사용자와 PC에 종속되어 다른 PC로 옮겨 재사용할 수 없다.

## 제거

로그인 시 실행을 해제하고 연결을 정상 해제한 뒤 트레이에서 종료한다. 설치형은 Windows의
설치된 앱에서 DK-Drive를 제거한다. 휴대용은 압축을 풀었던 프로그램 폴더를 삭제한다.
설정과 복구 파일은 자동 삭제하지 않는다.
완전 제거가 필요하다면 보존 파일을 먼저 내보내고 위 설정·캐시 폴더를 별도로 정리한다.
WinFsp는 다른 프로그램도 사용할 수 있으므로 DK-Drive 제거와 별도로 판단한다.

## 알려진 제한

- 실행 파일과 설치 관리자 코드 서명, 자동 업데이트를 제공하지 않는다.
- 전송 중단 지점부터 이어받기는 지원하지 않는다. 보존 파일의 명시적 재시도를 사용한다.
- 파일 내용 읽기 캐시는 없으며 메타데이터는 최대 2초 재사용한다. 외부 변경은 새로고침 후 반영될 수 있다.
- Implicit FTPS 실서버, 장시간·전송 중 단절, 로그인·시스템 종료의 잔여 실환경 검증이 남아 있다.
- 앱이나 Windows 버퍼에서 아직 전달되지 않은 데이터는 복구 캐시에 없을 수 있다.

## 체크섬 확인

다운로드한 파일 옆 `.sha256` 파일의 값과 다음 출력의 Hash를 비교한다.

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\DK-Drive-0.9.2-windows-amd64-setup.exe'
```

압축을 푼 후 dkdrive.exe의 SHA-256을 SHA256SUMS.txt와 비교할 수도 있다.
체크섬은 전송 중 손상 확인용이며 코드 서명을 대신하지 않는다.
